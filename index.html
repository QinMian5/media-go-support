Media Go 使用支持

Media Go 是面向开发者的 iPhone 音频采集工具。配置采集按钮、用途和标注字段，以整段上传或持续上传方式，将录音交给你自己的接收端保存。也可先在本机录音、标注和回放。

当前试用版需要 iOS 26 或更高版本。每位试用者自行配置接收端，App 不提供公共媒体服务器。

先试一次本机录音

  1. 打开「采集」，点按采集按钮，并允许麦克风访问。
  2. 录一小段测试音频，停止后确认标注。
  3. 打开「媒体」，查看条目并回放。尚未绑定接收端的录音保存在本机。

配置自己的接收端

  1. 准备符合 Media Go 接口契约 的接收服务。手机必须能访问它的完整 URL。
  2. 在「设置」中填写接收地址。若服务器需要认证，启用「使用 Authorization」，填写完整请求头值，例如 Bearer your-token。
  3. 执行「测试连接」，随后保存。普通文件存储地址或返回 HTML 的页面不能直接充当接收端。
  4. 录音并确认标注，在媒体页核对上传结果；也在自己的接收端核对收到的音频和标注。

公网连接请使用 HTTPS。普通 HTTP 本身不加密；局域网或 VPN 内的接收端应限制可访问人员。开发者提供的联调接收器读取接口没有认证，只适合可信网络。试用者收到接收器包后，可按包内运行说明启动它。

两种交付方式

  • 整段上传：停止录音并确认标注后，上传完整音频。
  • 持续上传：录音过程中就发送片段，确认后提交录音清单和最终标注。

临时断网时，本地内容保留，连接恢复后继续交付。删除本地条目不会撤回已发送的片段，也不会删除接收端保存的数据。已上传音频默认在 7 天后允许本地清理；可在设置中调整。
