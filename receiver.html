接收端接口

接收服务使用同一 URL 接收 multipart/form-data POST。音频为 PCM16 / WAV、48 kHz、单声道。支持整段上传、片段上传、录音清单提交和连接测试。

查看或下载完整接口契约（Markdown）

  • file：完整音频与最终标注。
  • segment：音频片段与顺序、时间范围。
  • finalize：清单、采集情况和最终标注。
  • test：测试连接，不保存媒体。

保存完成后返回 HTTP 200 与 {"status":"received"}。连接测试返回 HTTP 200 与 {"status":"ok"}。成功响应必须代表服务已经实际保存相应内容。

请按完整契约处理幂等、认证、错误回执和缺失片段。参考接收器仅用于可信网络，不应将未认证的媒体读取接口直接暴露到公网。
